<dl>
<dt>Activity</dt>
<dd>Any course material that is gradeable, e.g. multiple choice question sets, a lab, a programming assignment, an essay solicitation.</dd>

<dt>Dasko Course</dt>
<dd>An academic course that is created and managed in the Dasko ecosystem.</dd>

<dt>Grader</dt>
<dd>A user of a Dasko course that is responsible for grading student submissions.</dd>

<dt>Instructor</dt>
<dd>A user of a Dasko course that is responsible for teaching students.</dd>

<dt>Submission</dt>
<dd>Any gradeable artifact generated by a student when interacting with an activity, e.g. a selection for a multiple choice question, a student's demo to a grader, code, an essay.</dd>

<dt>Student</dt>
<dd>A user of a Dasko course that is being evaluated in the course.</dd>

</dt>
